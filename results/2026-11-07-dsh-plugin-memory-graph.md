# 六人物记忆系统评测：大肥鱼好记性（dsh-plugin-memory-graph）作者侧自测

[大肥鱼好记性](https://github.com/YeStarOne/dsh-plugin-memory-graph)（DSH 的会遗忘长期记忆图谱插件：四阶段抽取 → 每聊天一个 JSONL 图谱库 → 向量 + 图混合检索）按仓库接入说明跑完整卷：六人物、714 题、每人 182 天历史（2,346 轮逐轮回放）。

既有对话逐轮回放，每个逻辑日跑一次原生维护（衰减 / 裁剪 / 压实 / 主题归纳）；每题以问题原文强制调用原生检索 topN=10（同 Suzu 强制检索口径），另带最近六个完整回合，交给统一作答模型 glm-5.3-flash。

**判卷口径：提交方自判**——`judge-prompt.md` 原文 + glm-5.3-flash 单票，`grade.py` 做校验与汇总。这不是维护方的 Codex 判卷，也未做人工抽查，与其他批次的成绩**不可直接比名次**，仅供复现参考。

## 规模与成本（作者侧记录）

- 回放 2,346 轮 → 6 个独立 JSONL 图谱库、去重 4,432 条记忆实体；作答链路（抽取+嵌入+作答）按公开单价折算约 ¥2.91，平均每通过 1 题 ¥0.0058。
- 全程追加写本地 JSONL + 每逻辑日一次维护，无全图重建；判卷（346 次调用）属评测开销，不计入。
